## Project Overview

The Norad Capital website was created to provide the company with a professional digital presence and communicate its services clearly to individuals and businesses. The project focuses on responsive design, reusable components, accessible navigation, performance and a consistent visual identity.

## Main Features

- [x] Responsive layout for mobile, tablet and desktop devices
- [x] Multi-page navigation with React Router
- [x] Dedicated pages for company information and financial solutions
- [x] Reusable interface components and consistent visual system
- [x] Motion effects and interaction feedback with Framer Motion
- [x] Contact and conversion flows connected to the company's channels

## How to Run the Project

### Requirements

- Node.js 20 or later
- npm

### Installation

```bash
git clone https://github.com/brielmarca/Projeto_Norad_Capital.site.git
cd Projeto_Norad_Capital.site
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

## Scope and Data Handling

This repository contains the public-facing institutional website. It does not process loan applications, store customer financial data or provide an authenticated banking environment.

## Deployment

The application is generated as a static frontend and deployed on Cloudflare Pages. Environment-specific values must be configured through the deployment platform and must never be committed to the repository.
